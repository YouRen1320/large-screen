# 病房床位状态可视化看板

> 一个基于纯前端技术栈的医院病房床位实时监控看板系统，采用现代化科技UI设计风格。

## 📋 项目简介

本项目是一个针对医院病房管理的可视化数据看板，实时展示床位占用情况、患者信息、医护人员值班状态及各项统计数据。采用深色科技主题，适合大屏展示。

## 🎯 功能模块

### 左侧面板（数据统计区）

#### 1. 床位占用排行榜（左上）
- 展示各病区床位占用率排名
- 实时更新各科室床位使用情况
- 支持按占用率排序

#### 2. 床位趋势图（左中）
- 折线图展示近7天床位占用趋势
- 多条折线对比：总床位、占用床位、空闲床位
- 支持数据点悬停查看详情

#### 3. 患者来源分布（左下）
- 横向柱状图展示患者来源地区
- 动态数据更新
- 颜色区分不同来源

### 中间主视图（床位实时监控）

#### 病房床位 2D 平面图
- 网格化展示所有床位布局
- 三种状态实时标识：
  - 🟢 **空闲** - 可分配床位
  - 🔴 **占用** - 已入住患者
  - 🟡 **待消毒** - 清洁中
- 点击床位查看详细信息
- 支持快速状态切换（演示模式）

### 右侧面板（信息中心）

#### 1. 医院信息栏（右上）
- 医院名称：国内大型三甲医院
- 实时时间显示
- 当前日期（年月日 星期）
- 当前天气和温度

#### 2. 值班医护信息（右二）
- 当前值班医生列表
- 当前值班护士列表
- 联系方式
- 头像展示

#### 3. 床位状态分布（右三）
- 饼图展示床位状态占比
- 空闲/占用/待消毒百分比
- 实时数据更新

#### 4. 科室统计数据（右四）
- 各科室床位数统计
- 床位周转率
- 平均住院天数

## 🛠 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
  - Flexbox布局
  - 渐变和阴影效果
  - CSS 动画
- **JavaScript (ES6+)** - 交互逻辑
  - LocalStorage 数据持久化
  - DOM 操作
  - 事件处理
- **ECharts 5.x** - 数据可视化
  - 折线图
  - 柱状图
  - 饼图

## 🚀 快速开始

### 方式一：直接打开
直接双击 `index.html` 文件在浏览器中打开。

### 方式二：本地服务器
```bash
# 使用 Node.js http-server
npx http-server -p 8080

# 或使用 VS Code Live Server 插件
```

访问：`http://localhost:8080`

## 🎨 设计特色

- **深色科技风格**：暗蓝色背景 + 荧光蓝点缀
- **数据动态更新**：环境数据每5秒自动刷新
- **交互友好**：床位点击切换状态
- **响应式设计**：适配不同分辨率屏幕
